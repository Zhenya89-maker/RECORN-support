# RECORN Telegram Feedback Bot

Красивый бот обратной связи для RECORN: баги, жалобы и предложения.

## Запуск
1. Создай бота у `@BotFather` командой `/newbot` и скопируй токен.
2. Узнай свой Telegram ID. Для получения обращений в группу добавь туда бота и укажи ID группы.
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `ADMIN_CHAT_ID`.
4. Установи Python 3.10+ и выполни:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

## Важно
- Не публикуй токен в GitHub и не отправляй его другим людям.
- Для работы 24/7 нужен хостинг, который поддерживает постоянно работающий Python-процесс.
- Бот собирает только обращение, ссылку и необязательный контакт; не проси пользователей присылать пароли.
